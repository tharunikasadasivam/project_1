# 📊 Student Performance Analysis

A complete end-to-end data analysis project that generates a synthetic student dataset,
performs statistical analysis, runs SQL queries, and produces 10 professional visualizations
with an interactive HTML dashboard.

# APP LINK : https://project1-rgzrshejubj6gwrhp5xhlu.streamlit.app/

---

## 🚀 Features

- ✅ Synthetic dataset generation (500 students, 5 subjects)
- ✅ SQLite database with 7 analytical SQL queries
- ✅ Statistical analysis — mean, median, variance, std, correlation
- ✅ Auto-generated key insights
- ✅ Power BI ready CSV export
- ✅ 10 Matplotlib + Seaborn charts
- ✅ Interactive HTML dashboard (shareable single file)
